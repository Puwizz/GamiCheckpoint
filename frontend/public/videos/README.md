# GamiSenpai Tutorial Videos

Place the 6 tutorial video clips in this directory with the following naming convention:

- `step-1.mp4` — Square Base tutorial (from flat paper to layered square base)
- `step-2.mp4` — Kite Folds tutorial (folding side edges toward center)
- `step-3.mp4` — Bird Base tutorial (petal fold to narrow bird base)
- `step-4.mp4` — Neck & Tail Setup tutorial (lifting neck & tail points)
- `step-5.mp4` — Head Fold tutorial (folding head downward)
- `step-6.mp4` — Completed Crane tutorial (spreading wings open)

### Recommendations
- **Resolution:** 720p (1280x720) or 1080p (1920x1080)
- **Framerate:** 30 fps
- **Format:** MP4 (H.264 video, AAC audio)
- **Duration:** 15–40 seconds per step
- **Camera Perspective:** Top-down table view with clean contrast against white paper
- **Fallback:** If a video file is absent, the web UI automatically falls back to static reference images from `/static/references/step-X.png`.
